https://github.com/llimllib/hatchat

Something I've wanted for a long time is a slack-like chat server which:
- is built on sqlite
- is a single binary

The idea is that for small communities, it doesn't take much to run a chat server and I'd like one that optimizes for simplicity and deployability.

I had made a decent start at the app a long time ago, but dropped it because it seemed like just too heavy a lift for a single dev, and I couldn't maintain the energy. However, emboldened by my recent successes using claude to develop [[mdriver]] and [[aver]], I went back to it with agentic coding.

I've made great strides - it seems like it would maybe be kind of usable as it is?

I'm going to hack on it further before I actually deploy it anywhere, but feel free to follow along at the repository if you'd like or message me on mastodon or bsky if the project sounds interesting to you.
