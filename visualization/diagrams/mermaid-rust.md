https://github.com/1jehuang/mermaid-rs-renderer

`mmdr` is a mermaid renderer that is much more straightforward than `mmdc`(the mermaid CLI), which opens up a headless browser and essentially screenshots a diagram (!).

It's got some ways to go ([example bug](https://github.com/1jehuang/mermaid-rs-renderer/issues/27)), but it can be useful already for basic diagrams - I made a Claude program the other day that used it to render jira ticket dependencies and it did fine.
