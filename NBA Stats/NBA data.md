https://github.com/llimllib/nba_data

My github archive of parquet-formatted NBA data. Actively developed and should be current from 2010-today

- One neat feature of it is that, due to restrictions on the Azure IP space, I had to use tailscale to set up the downloading to come from my home IP
	- I got that idea from [Simon Willison](https://til.simonwillison.net/tailscale/tailscale-github-actions#using-the-exit-nodes-name-instead-of-an-ip-address) and improved it a bit from there. It's been working great for the last year or so
